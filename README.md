# ml_lib_comparison
- Project Title:
  Machine Learning Libraries Comparison

- Objective:
  The objective of my project is to compare python libraries on machine learning and deep learning like scikit-learn, pytorch    and tensorflow. Rather than differentiating within libraries which is totally unfair as these libraries are built for          different purposes, I will examine algorithms like linear regression, classification, neural networks etc.The comparison is    made on identical datasets and similar models based on measures of time, memory, accuracy etc.

- Installation Steps:
  Install anaconda environment and then,
  pip install -r requirements.txt(contain all the install to be things)

- Required Libraries:
  pandas, numpy, scikit-learn, tensorflow, pytorch & three datasets(given) required
  if running on Google colab nothing is required except interner.
  
- Instruction on how to run the project:
  Run notebooks on Jupyter Notebook, app using QR code or link to the deployed app.

- Expected output:
  You will get Accuracy, Train & Prediction time and Memory peak from every library. Also get some metric for regression(root    mean square value, R-squared) and classification(confusion matrix, F1 score) problem.
